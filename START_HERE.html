Before every live

Three steps. That is the whole thing.

1 Start the dashboard

Open the folder kalodata-live-dashboard and double-click start.command.
Full path: /Users/michaelmatthews/kalodata-live-dashboard/start.command
A black window opens saying DASHBOARD IS RUNNING.
Leave it open the whole live. Closing it stops everything.

2 Tick the auto-check box

In the browser click the 🔴 LIVE Log tab, then tick:
🔄 Auto every 5 min
It starts OFF every time, so tick it every live. That is your only click.

3 During the live

Every ~15 minutes, reach over and hit the download icon on the TikTok LIVE Board.
That is it. The dashboard pulls the file in within 5 minutes, updates the curve, and updates the STAY / SWAP / END badge.
Want it right now? Hit ⚡ Update from latest download for an instant refresh.

📱 Watch from your phone or iPad

Same wifi, open: http://192.168.68.61:8787
If that address ever stops working, the black window prints the current one.

✓ After the live

Double-click send_to_railway.command.
It uploads your exports to the always-on dashboard at kalodata-production.up.railway.app so Railway holds the permanent record. Safe to run twice, it never duplicates a stream.

! Why Railway cannot do this by itself

Railway is a server in a datacenter. It has no path to this MacBook's Downloads folder. That is a hard security wall, not a setting anyone can flip. That is the whole reason the live dashboard runs here and Railway is the after-the-fact record.

? If something goes wrong

"Address already in use" — start.command already handles this. If it still complains, close the black window and double-click again.
Nothing importing? Check the file actually landed in Downloads. The dashboard only picks up files with live, dashboard, creator or performance in the name.
